> **A tournament host can create, run and share a grassroots football tournament without spreadsheets or WhatsApp calculations.**
# Tournament formats
- Round robin
- Knockout
- League → knockout stage
# Tournament setup
Host can configure:
- Tournament name and description
- Venue and dates
- Team size
- Teams
- Players and rosters
- Tournament format and stages
- Group allocations and qualification rules
- Number of fixture rounds
- Knockout progression rules
- Automatic fixture generation
- Manual fixture ordering and scheduling
- Tournament branding    
- Pay **₦2,000 once** to activate the tournament

Football scoring is fixed at **3 points for a win, 1 for a draw, 0 for a loss**
# Tournament management
Host can:
- View live, upcoming, completed, postponed and cancelled matches
- Start/end matches or enter a completed result directly
- Configure lineups and substitutes
- Record:
  - goals
  - assists
  - own goals
  - yellow cards
  - red cards
  - substitutions
  - penalty shootout attempts
- Correct/remove mistakes while the relevant stage remains editable
- Add and edit players
- Move players between teams or back to unassigned
- Mark players inactive/reactivate them
- Reschedule, reorder, postpone or cancel fixtures
- Create a replacement fixture for a cancelled fixture without changing the competition structure
- Withdraw teams
- Publish/unpublish the tournament
- Complete the tournament explicitly when all required matches are resolved
# Automatic competition logic
System handles:
- League/group tables
- P/W/D/L
- GF/GA/GD
- Points
- Team and player clean sheets
- Fixtures/results
- Top scorers
- Top assists
- Cards
- Best goalkeeper by goalkeeper clean sheets
- Qualification into knockout stages
- Knockout progression and byes
- Match resolution, including regulation, extra time, penalties and walkovers
- Recalculation after permitted corrections
- Stage locking once progression has become irreversible
# Awards
Automatically calculated:
- Top Scorer
- Top Assists
- Best Goalkeeper
- Most Yellow Cards
- Most Red Cards

Selected by the host before tournament completion:
- MVP / Player of the Tournament
- Best Defender
- Best Midfielder
- Best Forward

Statistical awards may have joint winners.
# Public experience
Every published tournament gets an unlisted, shareable public page with:
- Overview
- Live matches
- Fixtures & results
- Standings / groups / bracket
- Teams & players
- Player and team stats
- Match details/events
- Awards
- Audit history

Updates are real time. If the host records or corrects an event, affected public scores, standings and statistics update immediately.

The public tournament slug is stable and does not change when the tournament name changes.
# Accounts & permissions
For V1:
- An account is required before payment
- Anonymous users may configure a local draft up to Review
- Authenticated drafts persist
- One tournament owner
- Public viewers need no account
- No captain/team-manager accounts
- No co-admins yet
# Lifecycle
`Draft → Active → In Progress → Completed`

Visibility is separate: `Published | Unpublished`
- Payment moves a configured draft into **Active**
- First match start moves the tournament into **In Progress**
- Completion is an explicit host action
- **Completed is permanently read-only and cannot be reopened**
# Explicitly out of scope
- Player tiers / captain drafts
- MVP/public voting
- Registration/payment collection from players
- Referee accounts
- Team-specific admin accounts
- Co-admins / granular permissions
- Chat
- Push notifications
- Historical player profiles across tournaments
- Advanced disciplinary/suspension rules
- Custom builders for arbitrary tournament formats
- Multiple venues
- Native apps
- Tournament discovery feed
- Automated match timers
- Enforcement of substitution limits/rules
